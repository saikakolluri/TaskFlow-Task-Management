# TaskFlow – Task Management Application

## 📌 Project Overview

TaskFlow is a simple and interactive Task Management Application developed using HTML, CSS, and JavaScript. It helps users create, manage, search, filter, edit, complete, and delete their daily tasks.

The application uses JavaScript to dynamically update the webpage and Local Storage to save tasks in the browser.

## 🎯 Project Objective

The main objective of TaskFlow is to provide an easy-to-use task management system while demonstrating JavaScript concepts such as variables, functions, arrays, objects, conditional statements, loops, array methods, DOM manipulation, and events.

## 👥 Target Users

TaskFlow can be used by:

- Students
- Employees
- Developers
- Anyone who wants to organize daily tasks

## ✨ Features

- Add new tasks
- Select task categories
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Search tasks
- Filter tasks by All, Active, and Completed
- Dynamic task counters
- Form validation
- Local Storage support
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
